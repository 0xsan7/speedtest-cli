# Security Policy

## Reporting Security Issues

If you discover a security vulnerability, please email santiagojerald734@gmail.com instead of using the issue tracker.

## Security Practices

- All data is stored locally on your machine
- No credentials or sensitive data are transmitted
- Speedtest.net connection is encrypted (HTTPS)
- No tracking or analytics

## Python Version Support

- Python 3.9+
- Older versions may have security vulnerabilities

## Dependencies

Keep speedtest-cli updated for security patches:

```bash
pip install --upgrade speedtest-cli
```

## Reporting Issues

For security concerns, please report privately first.
