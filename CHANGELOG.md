# Changelog

All notable changes to Speed Test CLI will be documented in this file.

## [1.0.0] - 2026-07-06

### Added
- Initial release of Speed Test CLI
- Download speed testing
- Upload speed testing
- Ping/latency measurement
- Test history tracking
- Average speed calculation
- Multiple test charsets support
- Simple test mode for faster results
- JSON history export
- GitHub Actions CI/CD testing
- Professional documentation

### Features
- Command-line interface with argparse
- Local history storage in JSON format
- Support for Python 3.9+
- Cross-platform compatibility (Mac, Linux, Windows)
